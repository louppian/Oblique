# COCO_VIT-L_14_224: modality gap 재현

COCO val2017 이미지 5,000장과 캡션 25,014개 전체를 후보로 사용했다. 검색 1위 캡션이 해당 영상의 캡션이면 정답으로 집계한다. 강건성은 이동 후 잡음 없는 예측과 잡음 추가 후 예측의 정확한 캡션 ID 일치율이다. 임계값은 중심화한 텍스트 행렬의 원래 특이값에 적용한다. 각 잡음 수준에서 100회, seed 2026, 이동값 사이에 동일한 잡음을 사용한다. 그림 1은 임계값에 따른 정확도·강건성, 그림 2는 중심화 임베딩과 gap의 코사인, 그림 3은 gap 변화 곡선이다.

모델 가중치는 고정했다. CLIP은 OpenAI 224px 체크포인트, SigLIP은 timm ViT-B-16-SigLIP WebLI 체크포인트를 사용했다. 논문에 세부 pretrained 식별자가 생략되어 있어 이 선택을 재현 조건으로 명시한다.

표의 accuracy와 robustness는 0~1 비율이다. step=0.0000은 원본, step=1.0000은 계산한 gap 방향 전체 이동이다.
