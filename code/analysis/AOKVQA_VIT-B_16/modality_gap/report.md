# AOKVQA_VIT-B_16: modality gap 재현

A-OKVQA validation 질문 1,145개, 질문당 보기 4개. 텍스트는 질문 + 공백 + 보기다. 질문별 영상 한 장과 원래 보기 4개로 gap 및 PCA를 계산한다. 정규화한 원래 임베딩에서 텍스트를 이동하고 제곱 유클리드 거리로 예측한다. 잡음은 텍스트에 독립 Gaussian으로 추가하며 표에 표준편차를 적었다. 100회, seed 2026, 이동값 사이에 동일한 잡음을 사용한다. 모든 이동값에서 잡음 없는 원래 예측이 유지되는지 검사했다.

모델 가중치는 고정했다. CLIP은 OpenAI 224px 체크포인트, SigLIP은 timm ViT-B-16-SigLIP WebLI 체크포인트를 사용했다. 논문에 세부 pretrained 식별자가 생략되어 있어 이 선택을 재현 조건으로 명시한다.

표의 accuracy와 robustness는 0~1 비율이다. step=0.0000은 원본, step=1.0000은 계산한 gap 방향 전체 이동이다.

## 문장 변경

질문당 500회. 정답은 direct_answers에서, 오답 세 개는 train·validation의 choices와 direct_answers를 합친 고유 답변 목록에서 정답 별칭을 제외하고 중복 없이 선택했다. 답변 목록의 분할 범위와 질문별 PCA는 명시적인 구현 선택이다.
